# 視窗（二）撲克牌益智遊戲：「九、十九、廿九」

### 專案簡介:
> 這是一款結合數字邏輯與環狀鏈結策略的單人撲克牌益智遊戲。遊戲剔除J、Q、K（共40張牌），核心目標是透過四排規律發牌機制，找出同排內「點數和為9、19或29」的連續三張牌組進行消除。遊戲整合了動態控制項增刪、跨圖層定位、首尾特殊連貫演算法以及非同步音效播放，全面考驗玩家在有限牌庫下的控牌佈局能力。

### 執行說明:
> 1. 遊戲初始化：程式啟動時自動洗牌，並依序在畫面上方生成四排、每排2張半疊加的撲克牌，右下角則固定顯示公牌牌背與剩餘牌數（初始為 32 張）。
> 2. 點擊發牌：滑鼠點擊右下角「公牌牌背」，程式會播放發牌音效（shu），並智慧跳過已被完全消除空掉的排數，依序將新牌發至該排的最下方，同時扣減剩餘牌數。
> 3. 觀察與消除：當玩家發現某排有符合條件的牌組時，點擊該排任意一張牌，程式即自動驗證。若不滿足3張則觸發防呆；若符合9、19、29（含直線連續、一上加兩下、兩上加一下等頭尾連貫組合），則播放消除音效（pa），並將牌面移出畫面、自動往上縮緊補齊，同時將消除的3張牌回收至手中公牌堆作為補充，使剩餘牌數增加
> 4. 局勢勝負：若順利將桌面與牌庫的所有牌張全數清空即跳出「勝利」提示；若公牌歸零且檯面無牌可消，玩家可點選「再玩一局」重啟新局，或點選「結束遊戲」關閉視窗
